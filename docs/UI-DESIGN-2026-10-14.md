# Cloudia — one sky, one dock

Agent-selected design direction, 14 October 2026. User delegated UI decisions. Reference image: `images/ui-2026-10-14/concept.png` (1672 × 941). Generated design concept, not a renderer screenshot. The generated cloud/terrain is NOT an application asset or evidence of renderer quality.

## Before implementation: contract and inventory

- Composition: compact serif Cloudia wordmark top left; morphology/weather subtitle; hands disclosure top right; one centered bottom dock with pause, four weather presets, Regola; vertical approach controls bottom right.
- Inspector: right desktop panel, mobile sheet above the dock. Header “Regola il cielo”, explicit close, three tabs Nube / Atmosfera / Misure. Single scrollable content region; retained tab on reopening. Only one disclosure open at once.
- Tokens: ivory #f4edda, text #eeeee7, secondary #b9c3c5, charcoal #202a2d (96% panel, 93% dock), sage #cbdcaa, white 16% border. Spacing 4/8/12/16/24/32. Control radius 9 px, surface radius 16 px. Commissioner system fallback for controls, Georgia for wordmark. Minimum 44 px interactive targets. 180–220 ms opacity/transform, reduced-motion alternative. Closing fades progressively enhance browsers supporting `::details-content`; native immediate close is the fallback.
- Components: outline SVG icons (20px, 1.6px stroke), weather button with selected fill, icon-only action with accessible name/title, native select, range + percentage output, two-column action group, native disclosure, ARIA tabs with roving tabindex and arrow/Home/End navigation.
- Copy: Cloudia.; Cella inclinata / current morphology; current weather; Mani, in arrivo; Trascina per esplorare · Scorri per avvicinarti; Sole / Tramonto / Pioggia / Temporale; Regola; Regola il cielo; Nube / Atmosfera / Misure; Forma, Vento, Avvicinamento, Dispersione; Raffica, Disperdi, Ricondensa, Nuova forma. Accessible close/pause/zoom/reset labels remain explicit.
- Necessary additions beyond concept: preserve all existing atmosphere, lightning/audio, quality, benchmark, orbital camera, light direction, restart and ground controls in the inspector. Keep actual runtime status and error reporting. No camera activation and no reduced rendering quality.
- Mobile: compact 6-item dock (pause, four weather, settings), icon + short text weather presets, zoom above dock on right. Sheet bounded by viewport and safe areas. Header/help adapt to short heights. No second toolbar.
