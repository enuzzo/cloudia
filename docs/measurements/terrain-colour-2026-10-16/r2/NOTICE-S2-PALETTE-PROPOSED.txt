Changes and derivation: partial overview4 source crop and exact projected-area,
valid-aware averaging to a 2048x2048 reference grid of 62.5m cells around 44N 10E;
local equirectangular axes X west / Z north. A source pixel was admitted only
when all four DN values were in 1..10000 inclusive (scale 0.0001). For the colour
reference, samples were selected on a 250m lattice, valid area>=0.99, WorldCover
class 10 (tree cover) or 30 (grassland) fraction>=0.95, combined NoData/cropland/built/
water fraction<=0.01, proxy Y in [0.02,0.60], excluding the prefixed grey/bright
heuristic(minRGB>=0.25 and range<=0.12). This is not an official cloud mask.

For each admitted class, the component median of RGB/Y was renormalized to Y1
using Y=0.2126R+0.7152G+0.0722B. A common per-channel correction factor was then
derived against the equal-weight arithmetic centroid of the four original
authored tree RGB endpoints (class 10) or two grass RGB endpoints (class 30):
chromRef=centroid/Y(centroid), factor=targetMedianY1/chromRef. Each endpoint was
multiplied by this common RGB factor, then normalized by the scalar
Y(originalEndpoint)/Y(correctedEndpoint). This preserves its authored luminance
and pairwise log-channel-ratio contrasts, up to Float32 rounding. It does not
force the final rendered distribution to equal the satellite distribution.

Only these authored tree/grass constants are derived. No satellite optical
texture is distributed or sampled by this colour-only trial. No palette for
sparse bare/shrub samples is inferred. WorldCover tree cover may include
plantations/orchards and is not a certification of natural forest.

Annual composite reflectance contains illumination, shadows and mixed dates;
no physical albedo/BRDF recovery, radiometric calibration of the renderer,
image repair, official endorsement or accuracy guarantee is claimed. The
scientific reference visualization uses a separate fixed gain 3 and sRGB OETF;
this display transform is not used for the authored colour derivation.
