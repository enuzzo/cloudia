# Face-direct A/B/A saved-data analysis — pre-data protocol

The analysis reads saved files only, after root confirms the inputs are ready. It performs no browser, GPU, model build, raycast, shader execution or image alteration. Current inputs are `browser/baseline-a-audit.json`, `candidate-b-audit.json`, `return-a-audit.json`; A native metadata are `baseline-a-native.json` / `return-a-native.json` and their corresponding `*-native-alias.json`. Outputs stay inside this analysis directory.

Freeze ordinary A and return A whole RGBA32F SHA-256 to `07fa43ec5de6d77b9bdf83d5a78e73cb607ae573d875ce382b3c28f909fb2fb9`, and A native PNG SHA-256 to `6d7a8c836c0ae51ca058c6b634e633481eb42e61f09f20b5be68bed128625fc9`. Native dimensions are 2474×1844. Both cached/fresh reads in all three owners must be qualified, stable, identical and complete; B's cached/fresh whole hashes must match each other. Whether B differs from A is reported, not fabricated or automatically equated with improvement.

Require the reported entire alpha SHA-256 and byte count to be equal for all six full reads; 4 bytes × 2474 × 1844 = 18,248,224 alpha bytes per read. Separately compare all twelve selected alpha uint32 words across all phases and cached/fresh reads. Decode saved RGBA directly from their uint32 words and cross-check JSON values, preserving signed-zero bits. Reject missing, nonfinite, nonpositive-distance or duplicate/misordered witness records. The fixed twelve IDs/coordinates are inherited without replacement; artifact/control are historical labels.

Snapshot gates compare camera pose/projection/target/ground and comparison controls; full recorded lighting; weather parameters; paused/no-orbit state; seed, quality/nominal steps, output/internal/canvas dimensions, output mode, density sampling, optical material selection, cloud and detail volume dimensions, flow mode and ablation. Require full quality: ultra, 384 nominal steps, 256³ macro, 128³ detail, native screen output and active optical texture. Ignore per-owner texture UUIDs, timing/counter fields and `probeAgeMs`; these are not pose or quality. Time-dependent values that are not in this gate remain available in the original snapshots; no cross-owner timing equivalence is inferred from this analysis.

The expected immutable mode labels are `ordinary-smooth` for A/return A and `geometric-fragment-Y-positive` for B (`snapshot.terrainDirectMode`). Compare the geometric subset of `snapshot.terrainRaster` exactly, including refinement metadata, geometry bytes, normal policy and lookup bytes. Require the canonical counts 591,788 vertices, 1,182,550 triangles, 33,127,816 geometry bytes, 2,949,120 lookup bytes and zero per-frame CPU height samples. These are reported statistics, not independently read-back vertex buffers or a certificate of global geometry identity. Equal whole alpha establishes identical reported receiver distance/miss bits for this fixed view, not a raw depth-buffer comparison.

A aliases have schema `native-png-exact-content-alias-v1`, reference the matching newly exported native DTO, and carry `actualExportSHA256`, `bytes`, dimensions and an absolute `existingExactPNG` path. Require the actual export DTO's PNG hash to match the pinned A PNG; rehash the existing bitmap and verify its byte count and PNG IHDR dimensions against both DTO and alias. The alias is evidence of identical encoded content already held locally; it is not a new transfer or a newly rendered pixel inspection. Compare the native DTO's relevant controls to its corresponding audit snapshot. B's separate PNG/transfer and independent artistic review remain root's evidence.

For each point retain A/B/return RGBA, raw bits, B−A RGB/luminance delta, B/A ratios and return−A bit equality. Luminance is linear `0.2126R + 0.7152G + 0.0722B`, before atmosphere/cloud/film. For each L1/L2/L3 pair, compute signed artifact−control luminance delta, artifact/control ratio, relative delta and signed Michelson contrast `(Ya−Yc)/(Ya+Yc)` in A/B/return; report B−A changes in those metrics. Zero denominators yield null, never an invented finite ratio. Pixel RGB change counts refer only to these twelve selected pixels, not the full frame.

The candidate changes the source formula for direct-light D, but this A/B/A test does **not** read D, the derivative face normal or the material factors. Saved RGB differences may be causally associated with the controlled shader substitution after the gates pass; they do not supply measured D values, certify physical correctness, prove a whole-ribbon mechanism, artistic acceptance or FPS. Any failed gate produces an unqualified report with no effect attribution. No threshold/strength/pixel selection is tuned after seeing B.
