# Fixed terrain navigation helper

Protocol frozen before execution: a pure yaw offset in radians, indexed by measured elapsed milliseconds. Root subtracts the two-second benchmark warmup from its measurement clock before calling the helper. Thus the full warmup has `elapsedMs <= 0` and offset exactly positive zero. The thirty-second measured path is `0.16 * sin(2 * pi * elapsedMs / 10000)`: three complete ten-second cycles. Every finite time at or before zero, and at or after 30,000 ms, returns exactly positive zero. NaN and either infinity throw RangeError. Intermediate whole/half-cycle crossings may have the ordinary floating-point residual of Math.sin; the window endpoints are explicitly clamped.

The module has no imports, mutable state, GPU, material, geometry, simulation-time or OrbitView dependency. Root applies its offset only while an explicit `profile=1&navAudit=1` measurement is active, adds it to the measured camera yaw without altering user controls, records the frozen specification, and restores zero outside that measurement. Both candidate modes must share this same function and measured clock origin; an interactively rotated page is not a matched trajectory.

The test file checks analytic quarter-period witnesses, exact warmup/end clamping, three extrema pairs, periodicity/antisymmetry, fixed-sweep bounds and deterministic repeat values, plus finite-input rejection. Existing Git-ignored/untracked node_modules was verified locally with Dropbox ignore attribute `1`. No dependency installation is needed. Helper validation is limited to a pure CPU run under ten seconds; root runs integrated Vitest/typecheck/build as required. No model, browser or GPU execution belongs to this helper.

Validation status: a pure CPU check passed 4,036 assertions using TypeScript transpilation plus `node:assert` against this module (17.654 ms measured after loading TypeScript; process wall time below one second; external ten-second alarm). Checks included analytic samples, exact clamps, periodicity, antisymmetry, deterministic values, 3,001 bounded finite sweep samples and nonfinite rejection. This was not an integrated Vitest run or full typecheck; root runs the saved test file after integration. No browser, GPU or model was used.
