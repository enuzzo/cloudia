# Outflow structural anchoring — independent prefix preflight plan

**Pre-execution plan. No real recipe or volume has been executed.** This work owns only this preflight directory. Root owns the source snapshot/Engine; the layout implementer owns `volume.ts` and the new anchoring helper. No candidate volume file is edited by the reviewer.

The existing product contract is `assertJointLayoutContract()` in `src/cumulonimbus/layoutPrefix.test-helper.ts`, imported by `volume.layout-regression.test.ts`. A separate canonical `jointLayoutContract.ts` was not found in the inspected product. The old extractor removes the size-cubed field/density allocation and the cellular feature lattice call, compiles the trusted generator prefix, and returns before the first lobe raster loop. It already records RNG call counters, tuple identity, foundations/summits, body/shoulder descendants and before/after the existing shoulder projection. `scripts/qa-layout.ts` additionally scans seeds 0–1023; **that scanner will not be run or copied as this preflight's default**.

The new bounded extraction will reuse strict, unique source anchors and the existing pre-raster boundary, adding snapshots around the structural operation and horizontal contraction. It will not reproduce a second recipe, sample a density, allocate a grid or call `generateVolume`, `generateDetail`, cellular noise, bake, raycast or GPU code. New helper imports must be explicitly whitelisted. Any unknown import/changed anchor fails closed. The original RNG body remains intact apart from counters, and every tracked lobe is identified by original object/append index.

Required numeric contracts, with the implementer's exact F/M/C and delta definition to be frozen before execution:

1. Record F/M/C and the selected mature summit before shape transforms, then the declared anchoring delta and its transformed counterpart. Check that only the requested structural component moves; preserve all unrelated tuple components exactly. The expected delta must be independently derived from the frozen F/M/C contract, not read back from the mutation itself.
2. Record lobe tuples/IDs and RNG counters immediately before the structural shift, immediately after it and before horizontal contraction. Require unchanged primitive count, append order, object uniqueness and every RNG stream/call count. Every cap/core/billow/streak intended by the frozen contract must receive the same prescribed displacement before contraction. Require all other groups unchanged at that stage; do not count a changed contraction as an unauthorized per-lobe structural edit.
3. Record X/Z `max(abs(center)+radius)`, limits 4.35/2.8 and the applied scales, with exact pre/post snapshots. Require one global linear contraction per axis, positive scale at most 1, every center and corresponding radius following it, and all Y/radiusY/blend components unchanged. Record extrema and representative endpoints; no clipping, clamping of individual centres or primitive append is permitted.
4. Preserve and re-run the existing joint-shoulder invariants on the resulting candidate prefix. Its expected “before” state must be taken after the candidate's new global structural/contraction operation. Do not compare the old baseline's final tuples as if they should equal a candidate whose global X/Z contraction legitimately differs.
5. Compare complete serialized Float64LE recipe tuples and RNG stream counts for unsheared seeds 72/73 against the authenticated 141-file v61 baseline. Require exact identity, including tuple lengths and signed-zero bytes; no tolerance for unchanged families. For the sheared recipe, record delta/contraction/projection separately and never assert baseline equality of the intended moved outflow.

Execution schedule is intentionally small: synthetic arithmetic/anchor fixtures after this plan, then—**only after root's source/protocol freeze**—the fixed real seeds 74,72,73, unless root explicitly freezes another short list. There is no adaptive replacement, seed search, broad scanner, full model, raster/bake, browser or GPU. Proposed bounded real-prefix budget: 2 CPU seconds, 5 wall seconds, 256 MiB process RSS; stop as incomplete on any limit, without dropping a difficult seed. Actual budgets/runner must be checked before execution because loading TypeScript itself can dominate memory; no unexplained rerun is allowed.

Record baseline/candidate source and helper hashes, extraction script hash, exact seed list, runtime/architecture, CPU/wall/peak RSS and all failed contracts. “Prefix PASS” means recipe arithmetic/structure only; it does not establish density continuity, cloud anatomy, lighting, native artistic acceptance or FPS. Dense/GPU work remains a separate root gate.
