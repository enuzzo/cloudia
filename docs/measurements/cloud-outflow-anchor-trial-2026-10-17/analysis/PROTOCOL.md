# Native A/B metadata validation — frozen before B data

Scope: validate the two actual native DTO/PNG pairs for seed74, front and side. The script reads no model, density field or GPU resource, starts no browser, and makes no performance or artistic judgement. Reading B is gated by `--execute-frozen-analysis` and root notification that both B poses are complete.

Inputs are `browser/baseline-74-{front,side}.json`, front exact-content alias, side PNG/transfer; future inputs are `browser/candidate-74-{front,side}.json`, matching PNGs and `-transfer.json` files. Baseline DTOs and transfer/alias metadata are pinned now. All 143 entries of source freeze R1 are hashed from the candidate source without importing or executing it. R1 SHA256 is `e809c77ed113331d54003d5d730a964c15b87589b794d634fe1d4e4286e08792`.

The world camera, entire lighting structure, material uniforms, weather controls, terrain/optical configuration, volume dimensions/formats, quality, output/internal dimensions, pause/orbit/speed, and render-affecting clocks must compare exactly for each corresponding pose. Required resolution is 256³ macro / 128³ detail / 16³ flow and 384 nominal steps at ultra quality. Unknown extra or missing metadata fields fail comparison.

Explicit exclusions, recorded with both values: rendererVersion and anatomyVariant identify A/B; frame serial/timestamps/date identify capture ownership; terrain-cache request/hit/submission/epoch counters identify owner activity; sky-texture UUID/version/requestSerial identify owner-local allocation/upload state. Their physical dimensions/type/colorSpace and requested light side still compare exactly. Geometry-derived `material.supportMin`, `material.supportMax`, and `weather.precipitationBounds` may change and are recorded. The native DTO has no density-content arrays or changing density-content counters: `densitySampling`, including formats, dimensions and payload accounting, remains exact.

An explicit pre-B exemption applies only to `clocks.weatherTime`. Source R1 `GPUSceneEngine.ts` SHA256 `d2279f60b29a373c66976af628f6783025ff96e4e883a6da01e4da237c9657c8`, line464 advances it while paused. Its render-affecting uses are lightning creation/intensity/scheduling in lines746–773; comparison-state setup clears lightning at line906. This owner wall/storm clock is not a shader uniform. Both numeric values and the source proof are reported. The exemption is valid only with paused=true, orbit=false, fully settled clear sky, zero current/target rain, zero overcast, haze1, zero dispersion, zero flash count/intensity and the entire lighting/material/weather controls matching after only the declared derived-bound exclusions. If these conditions fail, the exemption is invalid and metadata qualification fails. Other clocks remain exact: simulationTime, forcingTime, precipitationUniformTime, flowUniformTime, flowFieldTime and flowFieldDispersion. No post-result relaxation is allowed.

PNG validation checks file SHA256/byte length and IHDR dimensions against its actual DTO. For a transfer it reconstructs the canonical PNG data URL from the verified PNG bytes and checks every ordered part's character count/hash against the transfer ledger and the DTO's textExport. For baseline front it verifies the exact-content alias metadata and independently hashes the referenced existing bitmap. It does not infer a new transfer from an alias. A/B PNG hash equality/difference is recorded as content identity only and never scored as image quality.

Synthetic fixtures are saved before execution and import only the pure contract module. They exercise exact matching with allowed differences, camera/material/quality/clock changes, invalid lightning/weather exemptions, unknown metadata, PNG/transfer corruption, and alias provenance mismatches. The actual four DTO/PNG validation runs only after root authorization, once, with a 15s external alarm; the script imposes 10s wall / 5 CPU seconds / 512MiB process RSS, fixed four DTOs and 143 source paths. Missing or invalid input produces an explicit failed/incomplete report, without retry or scan.
