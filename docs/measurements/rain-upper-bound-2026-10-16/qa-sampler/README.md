# Standalone rain RG8 sampler audit

Prepared 2026-10-16; no GPU executed by the preparing agent.

Open the already running root server at http://127.0.0.1:4181/qa-sampler/ .
Press **Esegui audit GPU** once; the page performs no automatic GPU work.
The full report appears in `pre[data-testid="sampler-audit-json"]` and can be
saved with **Scarica JSON**. The report includes its canonical payload SHA256;
adding the integrity field is explicitly excluded from that self-hash.

## Scope and pass conditions

Raw WebGPU compute, no Three.js renderer: RG8UNORM texture2D, one mip level,
explicit textureSampleLevel level0, linear min/mag, clamp-to-edge, anisotropy1.
Every input UV is rounded to f32 before both CPU ideal and GPU evaluation.
Fourteen datasets use39,614 deterministic queries:13 synthetic fixtures plus
the64² seed72 map already generated by root. The real bytes are copied unchanged;
map SHA256 is checked before GPU device creation. No volume is regenerated.

The fixtures cover constant encodedG0/1/103/104/127/254/255, Rbyte1, a sparse
Rbyte1 with highG zero-R neighbors, corners/edges, a checkerboard, a finite halo
with remoteG255, and all-R-zero maps with constant/varyingG. Queries include
centres, f32 neighbors of centre/footprint transitions, half cells, Halton
interior points, UV endpoints and outside-domain points for clamp diagnosis.
The near-zero UV uses normal2^-24, not a subnormal that WGSL may flush to zero.

For actual GPU R>0, the check requires filteredG <= emission-halo maximum+1/255
and exact zero attachment at the guarded ceiling AND its next representable
f32 value. Three uploaded reciprocal heights1/1.25/(1/.68) exercise below/above
.72 and formation endpoints. A separately computed one-code G envelope tests
the arithmetic guard without relying on actual sampler overshoot occurring.
All-zero R maps require GPU R exactly zero. Nonfinite outputs or changed UV
echoes fail. CPU ideal R/G differences and four-corner maxima are diagnostic;
weight quantization can change ideal interpolation without violating the bound.

Storage result stride80B = sampled RG/UV16B +3 endpoint vectors48B + envelope16B.
Uniform size32B = two vec4<f32>. Readback/hash byte counts follow those layouts.
Each map releases buffers/texture in finally; the device is destroyed before the
final report is published, including on failure. The report records cleanup.
